> FINDINGS
>
> **F1 (Minor) — `_t` reports 0.0 or about 1e16 for a near-constant P&L series, depending on the last float bit.**
> - Invariant: I6, "0.0 mapping for undefined t".
> - Location: nodes.py `_t` (~line 1286), delegating to `newey_west_mean(lags=0)`.
> - Reproducer:
>   - `CondorQuoteBacktest._t([1.7, 1.7, 1.7])` returns 0.0.
>   - `CondorQuoteBacktest._t([1.7000000000000004, 1.7000000000000004, 1.7])` returns 1.326e16.
>   - It occurs naturally: PutSpreadQuoteBacktest with rng seed 113 in scratch harness.py (`scenario`, then `PARAMS` overrides as in oracle.py `check_run`) gives `implied_pnl_t` = 1.3e16 on 3 trades of 1.7 credit each. It reproduced in roughly 1 of 300 random runs, in both oracle.py and oracle2.py.
> - Consequence: a tiny book (2 to 5 trades with equal credit) can be ranked top by a t-stat driven by rounding noise. The existing test only covers exactly identical floats.
> - Family: numeric sentinel that is not robust to float noise. Only `_t` is affected.
> - Fix: treat a spread below a relative epsilon as zero variance.
>
> **F2 (Minor, disclosed) — the t divides by n, but ADR item 5 says "plain t".**
> - Location: `_t` via `newey_west_mean(lags=0)`.
> - Consequence: t is overstated by sqrt(n/(n-1)): n=3 by 1.225, n=12 by 1.044, n=30 by 1.017, n=100 by 1.005. The class docstring discloses it. The README and ADR do not. It matters only for small walk-forward folds.
> - Family: statistic definition drift.
>
> **F3 (Minor, disclosed) — put-spread benchmark needs dividend data, contradicting ADR item 2.**
> - Invariant: I3/I5, "put spread needs no dividend data".
> - Location: nodes.py `_benchmark`, calling `dividends_paid`. The class docstring discloses it.
> - Reproducer: strip `dividend_amount` from the underlying series. `PutSpreadQuoteBacktest.run` raises "dividend_amount on 2024-03-06 must be a finite number >= 0, got None". The condor raises the same via the call charge.
> - Consequence: the ADR non-goal "IWM possible later since a put spread needs no dividends" is not true of the shipped node. IWM's archive `dividend_amount` is None throughout (optionshist.py). No current consequence: the 14 documents are SPY/QQQ.
>
> **F4 (Minor, disclosed) — existing condor `american_charge_usd` and `pnl_usd` change in the last float digit when both charges are non-zero.**
> - Invariant: I7 ("existing metric values"), I3.

> - Reproducer: diff_condor.py (seeds 300) and diff_condor2.py (seeds 400). The differences, all last-digit:
