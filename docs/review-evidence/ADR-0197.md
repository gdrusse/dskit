# ADR-0197 review evidence

## Independent skeptic review — Luna

Initial verdict: **C0/M4/m0**. Luna reviewed design, implementation, leakage,
selection and available artifacts without editing files or rerunning training.

1. The ADR required strict development CRPS improvement plus lower/upper
   tail-score noninferiority, but the selector enforced only per-index 5%/95%
   hit guards. Resolved by adding JSON-declared equal-cell strict-improvement
   and noninferiority metrics to `_guard`, persisting all comparisons, and a
   failing-first rejection test. Phase F evidence shows all nine checks pass.
2. Dynamic PIT's shrinkage prior used every calibration PIT even when a generic
   caller supplied outcomes not mature at forecast time. Resolved by building
   each date's prior only from calibration rows with `end < forecast date`; a
   test changes immature labels and proves bitwise-invariant forecasts.
3. CUDA cleanup ran while final-batch tensor locals were still referenced and
   resource telemetry was console-only. Resolved by deleting those references
   before cache release and persisting `peak_rss_kib` plus stage wall time in
   each completion record. Bounded GPD anchor batches additionally reduce the
   valid late replay peak from 6.14 GiB to 3.63 GiB.
4. The standalone memo, review evidence, RE-ENTRY and journal entry were not
   yet present. These are exit artifacts, completed after the final report.

## Tests and execution

Focused core suite: **109 passed**. It covers causal/delayed PIT admission,
same-date batching, immutable future labels, immature calibration exclusion,
recency/sparse fallback, beta-pool identity and monotonicity, GPD center and
pooled tails, exact bounded anchor prediction, proper tail metrics, enforced
selection guards, and completion telemetry. The relevant child CDF study test
also passes. Broad child config tests retain 23 known pre-existing manifest and
approval-pin failures unrelated to ADR-0197 and were not rerun after the focused
scope passed.

Phase F is the sole valid evidence root. Search, selection, development, early,
middle, late and report have complete markers with matching config, panel,
provenance, inventory, implementation, selection and file hashes. External
resource observations are all below 30 minutes/6 GiB; slowest/peak is late at
4:03/3.63 GiB. In-process telemetry is also retained in each marker.

Final read-only re-review verdict after fixes: **C0/M0/m1**. Luna recomputed
every Phase F completion-marker file hash with zero mismatches, confirmed the
shared identity and frozen-selection hash, checked all nine promotion
comparisons, resources, partitions, counts, reported metrics and block
intervals. The sole Minor was an alternate aggregation in the memo's combined
later CRPS-skill table row (0.0827% versus the governed equal-cell paired point
0.08045%); the row was corrected to 0.08045%. No unresolved finding remains.
