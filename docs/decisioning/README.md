# Decisioning

Nothing is decided without a linked evidence file.

Each child keeps `docs/decisioning/`: a grid in `README.md` and one
short document per decision (command, configs, output, result).

The generated grid displays the full Path CSV. Its Actions table is a
display-only view of the latest 10 rows; `actions.csv` always retains the
complete append-only journal.
