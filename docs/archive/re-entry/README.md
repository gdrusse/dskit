# docs/archive/re-entry

Where re-entry notes go when `/wrap` replaces them. One file per lane
(`<child>.md`, `dskit-core.md`), newest note first, append-only, merged with
git's `union` driver. `2026-10-10-consolidated-history.md` holds everything the
single `docs/RE-ENTRY.md` carried before the per-lane protocol.

Read a lane's archive only to answer a history question. The current state is
the lane's own `RE-ENTRY.md`; the index is `docs/RE-ENTRY.md`.
