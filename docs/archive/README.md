# docs/archive

Nothing here is read at session start. `re-entry/` holds every replaced lane
note (one file per lane, newest first) and the pre-2026-10-10 consolidated
history; `todo/` holds closed `TODO.md` sections; `results/` holds the old
root-level RESULT files. Append, never edit; history questions only.

Archived re-entry notes retain their original text and mixed relative-link bases.
Follow links relative to the archive file first. For unresolved links copied from
old notes, try [the original docs directory](../) for core/consolidated history,
or [the original child docs directory](../../children/index_options/docs/) for
`re-entry/index_options.md`. Use [the current lane index](../RE-ENTRY.md) for
present status; a missing historical target is not proof of a current capability.
