# docs/archive

Nothing here is read at session start. `re-entry/` holds every replaced lane
note (one file per lane, newest first) and the pre-2026-10-10 consolidated
history; `todo/` holds closed `TODO.md` sections; `results/` holds the old
root-level RESULT files. Append, never edit; history questions only.

Archived re-entry notes retain their original text, including relative links.
Resolve links in `re-entry/dskit-core.md` and the consolidated history from
[the original docs directory](../); resolve `re-entry/index_options.md` links
from [the original child docs directory](../../children/index_options/docs/).
Use [the current lane index](../RE-ENTRY.md) for present status.
