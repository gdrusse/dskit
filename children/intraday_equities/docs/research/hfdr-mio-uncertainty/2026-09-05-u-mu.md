## Proposed decision

Create a joint uncertainty set `U_mu` for the vector of net conditional mean
returns. Build it from the same whole-session, cross-asset refits used for
mean-alpha intervals so it represents estimation uncertainty in the complete
model-selection procedure. Preserve paired candidate/name/horizon coordinates
and record model, feature, HPO, calibration, and cost hashes.

The optimizer may use a worst-case or lower-confidence alpha objective over
`U_mu`, but this set must not absorb realized-return shocks; those belong in
`U_r`.

## Research backing and judgement

Block bootstrap methods support joint confidence regions for dependent
statistics, and data-driven distributionally robust optimization formalizes
decisions against ambiguity sets:

- Politis and Romano (1994), *The Stationary Bootstrap*:
  https://doi.org/10.1080/01621459.1994.10476870
- Mohajerin Esfahani and Kuhn (2018), *Data-driven Distributionally Robust
  Optimization Using the Wasserstein Metric*:
  https://arxiv.org/abs/1505.05116

**Decision criterion: judgemental.** The set can be calibrated empirically,
but choosing its geometry and how pessimistically the objective reads it is a
capital-utility decision.
