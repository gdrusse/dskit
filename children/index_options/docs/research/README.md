# Research

Before buying or downloading data, confirm exact products/series, dates,
expired-chain completeness, quote sizes/conditions and timestamps, availability
and revisions, licensed underlying/official settlement values, costs, storage,
retention, two-machine use and publishable derived outputs. No source is approved.

Use record-research; dated findings are written only by the journal CLI:

```bash
python -m dskit.journal research "TITLE" --topic data-feasibility \
  --name synthesis --body-file /absolute/path/to/draft --root .
```

The draft must contain Question, Finding and Sources. Output goes to
docs/research/<topic>/<date>-<name>.md and appends an action.
Do not hand-write dated entries, hand-edit the generated decisioning README,
or promote the human owner's Path. This README is infrastructure, not evidence
of an acquisition, accepted license, completed study or trading edge.
