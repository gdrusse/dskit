# Plans

Project-specific plan builds: the phased work plans, build sequences,
and closeout checklists for THIS child. The dskit repo's `docs/plans/`
is repo-level; a graduated child keeps this folder as its own.

Short kebab-case Markdown, one file per effort: the problem, the
proposed sequence, the done-when. Results go to `docs/memos/` and
decisions to the journal — a plan never records outcomes.
